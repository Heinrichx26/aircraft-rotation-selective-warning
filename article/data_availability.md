The public code and reference results for reconstructing flight connections from the full January 2008 United States Airline On-Time Data cohort and for running constructed model examples are available at <https://github.com/Heinrichx26/aircraft-rotation-selective-warning>. The repository includes the analysis code, data download and integrity-check instructions, aggregate connection summaries, and a reproducible model-training example using constructed flight records. The domestic operational archive used for model fitting and evaluation is governed by aviation security, confidentiality and institutional access requirements. The article reports its cohort definitions, temporal partitions, model settings and aggregate results.
